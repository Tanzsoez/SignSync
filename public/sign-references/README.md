# Sign-reference assets

These 73 reference images were supplied in the project owner's shared Google Drive
folder and are grouped by dialect and curriculum type. The application maps them to
the corresponding ASL/FSL letter or number in `src/data/verifiedSignReferences.js`.

The images are teaching references, not an assertion of linguistic review or
certification. Keep ASL and FSL assets separate even when a handshape appears
similar. Dynamic signs may need video or a frame sequence to fully communicate
their motion; the current stills show their reference pose.
